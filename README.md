# handy-skills

Random skills for my personal things.

This repository contains small, reusable Agent Skills (skills.sh-compatible `SKILL.md` format) that I use across projects.

## Install

Add this skill collection with:

```bash
npx skills add https://github.com/nqd2/handy-skills
```

## Skills

- `harvard-resume-writing`
- `skillssh-find-skills`
- `device-inspector`

## Notes

- Skills are organized under `skills/`.
- Each skill folder includes a `SKILL.md` and may include scripts/docs.
- This repo is intentionally personal and experimental, so skills can evolve quickly.
